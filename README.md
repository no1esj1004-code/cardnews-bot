# 카드뉴스 자동화 봇

구글·다음·줌·시그널의 실시간 검색어, 구글 뉴스 연예 섹션, 유튜브 인기 동영상 등 **무료 수집원 7곳**에서 지금 뜨는 이야기를 모아 **연예·문화·밈** 주제를 매시간 골라, **채널 마스코트(손그림풍 샴고양이)가 설명해 주는** 카드뉴스를 만들고 인스타그램에 자동으로 올립니다. 카드마다 고양이가 그 내용을 보여주는 그림이 AI로 그려집니다.

```
매시 7분 (GitHub Actions)
 ├─ 1. 수집      실시간 검색어(구글·다음·줌·시그널) + 연예 뉴스 묶음(구글 뉴스) + 참고 신호(유튜브·디시)
 ├─ 2. 사실 확인  네이버 뉴스 검색(무료) → 키워드별 최근 48시간 보도 (언론사당 1건)
 ├─ 3. 선별·원고  Claude → 주제 1개 선정 + 카드 원고, 기준 미달이면 그 시간은 쉼
 ├─ 4. 안전장치   금지 키워드 / 근거 언론사 2곳 미만이면 게시 안 함
 ├─ 5. 그림       표지 1장 + 본문 카드마다 1장씩, 마스코트가 내용을 보여주는 그림 생성 → 말풍선 카드 5~6장
 └─ 6. 게시       인스타그램 캐러셀 업로드 (AI 생성 라벨 포함)
```

## 1. 준비물

| 무엇 | 어디서 | 용도 | 비용 |
|---|---|---|---|
| (구글·다음·줌·시그널·디시) | 준비할 것 없음 | 실시간 검색어, 연예 뉴스, 인기글 | 무료, 키 불필요 |
| 네이버 검색 API 키 | developers.naver.com → 애플리케이션 등록 → "검색" | 검색어를 뉴스로 확인 | 무료 (일 25,000회). **사실상 필수**: 없으면 다음·줌·시그널 검색어가 후보가 되지 못합니다 |
| YouTube Data API 키 | console.cloud.google.com → YouTube Data API v3 사용 설정 → API 키 | 유튜브 인기 동영상 | 무료 (일 10,000 단위 중 하루 24 단위 사용). 없으면 유튜브만 빠짐 |
| Anthropic API 키 | Claude 개발자 콘솔 (docs.claude.com 안내 참고) | 선별·요약·원고 | 종량제 (시간당 1회 호출) |
| OpenAI API 키 | platform.openai.com | 마스코트 그림 | 종량제 (게시물당 4~5장: 표지 1 + 본문 카드마다 1). 없으면 그림 없이 말풍선만 있는 디자인으로 대체 |
| 인스타 토큰 + 계정 ID | developers.facebook.com | 자동 업로드 | 무료 |
| GitHub 계정 | github.com | 매시간 실행 | 공개 저장소는 Actions 무료 |
| (선택) X API Bearer Token | developer.x.com | X 트렌드를 수집원에 추가 | 유료 종량제. 트렌드 조회 1회 약 $0.01 → 매시간이면 월 $7 안팎 |

수집 단계는 전부 무료입니다. 비용이 드는 곳은 원고를 쓰는 Claude와 AI 이미지뿐이고, 이미지 키를 빼면 Claude 비용만 남습니다.

각 콘솔에서 **월 지출 한도**를 꼭 걸어두세요. 가격은 수시로 바뀌니 등록할 때 각 사이트의 요금표를 확인하세요.

### 인스타그램 토큰 발급 (프로페셔널 계정이 이미 있는 경우)

1. developers.facebook.com 에서 개발자 등록 후 **앱 만들기**
2. 앱에 **Instagram** 제품 추가 → **"Instagram 로그인을 사용한 API 설정"** 선택
3. 내 인스타그램 계정을 연결하고 **액세스 토큰 생성** → 이 값이 `IG_ACCESS_TOKEN`
   - 필요한 권한: `instagram_business_basic`, `instagram_business_content_publish`
4. 같은 화면에 표시되는 계정 ID(숫자)가 `IG_USER_ID`
   - 화면에 안 보이면: `https://graph.instagram.com/me?fields=user_id,username&access_token=토큰` 을 브라우저에 붙여넣어 확인
5. 토큰은 60일 뒤 만료됩니다 → 아래 "토큰 자동 갱신" 참고

Meta 대시보드 메뉴 이름은 자주 바뀝니다. 막히면 공식 문서를 따라가세요:
https://developers.facebook.com/docs/instagram-platform/instagram-api-with-instagram-login

## 2. 설치 (약 30분)

1. GitHub에서 **공개(Public)** 저장소를 새로 만들고 이 폴더의 파일을 전부 올립니다.
   - 공개여야 하는 이유: 인스타그램 서버가 카드 이미지를 공개 주소에서 가져갑니다. API 키는 코드가 아니라 Secrets에 넣으므로 노출되지 않습니다.
2. 저장소 **Settings → Secrets and variables → Actions** 에서 등록합니다.

   **Secrets** (비공개 값)

   | 이름 | 값 |
   |---|---|
   | `NAVER_CLIENT_ID` / `NAVER_CLIENT_SECRET` | 네이버 검색 API (사실상 필수) |
   | `YOUTUBE_API_KEY` | YouTube Data API 키 (선택) |
   | `ANTHROPIC_API_KEY` | Claude API 키 |
   | `OPENAI_API_KEY` | 이미지 생성용 (선택) |
   | `IG_ACCESS_TOKEN` | 인스타그램 토큰 |
   | `X_BEARER_TOKEN` | X API Bearer Token (선택, 넣으면 X 트렌드도 함께 수집) |

   **Variables** (공개돼도 되는 설정)

   | 이름 | 예시 | 설명 |
   |---|---|---|
   | `IG_USER_ID` | `1784…` | 인스타 계정 ID |
   | `CHANNEL_NAME` | `지금뜨는` | 카드 좌상단 채널 이름 |
   | `CHANNEL_HANDLE` | `@my.channel` | 마지막 카드의 팔로우 문구 |
   | `DRY_RUN` | `false` | **이 값을 정확히 `false`로 넣기 전까지는 게시되지 않습니다** |
   | `QUIET_HOURS` | `1-6` | 게시를 쉬는 시간대 (KST). 비우면 24시간 |
   | `MAX_POSTS_PER_DAY` | `12` | 하루 최대 게시 수 (기본 24) |

3. **Actions 탭 → "마스코트 만들기 (수동)" → Run workflow** 로 캐릭터 기준 그림을 만듭니다. `assets/mascot_source.jpg`(모델이 되는 실제 고양이 사진)를 바탕으로 그립니다. 저장소의 `assets/mascot.png` 를 열어 보고, 마음에 들지 않으면 다시 실행합니다(실행할 때마다 새로 그립니다). 이 그림이 채널의 얼굴이 되니 여기서 충분히 고르세요.
4. **Actions 탭 → "카드뉴스 (매시간)" → Run workflow** 로 한 번 수동 실행합니다.
5. 실행 화면 아래 **Artifacts** 에서 `cards-…` 를 내려받아 카드와 `caption.txt` 를 확인합니다.
6. 하루 이틀 시험 모드로 결과물을 지켜본 뒤, 마음에 들면 Variables에 `DRY_RUN = false` 를 추가합니다. 그때부터 실제로 올라갑니다.

### 내 컴퓨터에서 먼저 보기

```bash
pip install -r requirements.txt
python main.py sample        # 키 없이 디자인만 확인 → output/sample/

python tests/test_sources.py    # 수집원 파싱·robots.txt 판정 점검
```

## 3. 고치고 싶을 때

| 바꾸고 싶은 것 | 파일 |
|---|---|
| 다루는 주제, 말투, 카드 장수 | `bot/editor.py` 의 `SYSTEM_PROMPT` |
| 절대 올리지 않을 단어 | `bot/safety.py` 의 `BLOCKED_KEYWORDS` |
| 마스코트 생김새·화풍 | `bot/images.py` 의 `MASCOT_DESCRIPTION`, `MASCOT_STYLE` 을 고친 뒤 "마스코트 만들기"를 다시 실행 |
| 마스코트 말투 | `bot/editor.py` 의 `VOICE_MASCOT` |
| 카드 디자인 (글자 크기, 배치, 색) | `bot/render_mascot.py`, 포인트 색은 `ACCENT_COLOR` |
| 마스코트 없이 운영 | Variables에 `MASCOT=false` → 주제 이미지 + 어두운 디자인(`bot/render.py`)으로 바뀝니다 |
| AI 이미지 비용 | Variables의 `IMAGE_QUALITY` (`low`/`medium`/`high`, 기본 `medium`), `CARD_IMAGES=false` 로 하면 표지에만 이미지 |
| 실행 주기 | `.github/workflows/hourly.yml` 의 `cron` |
| 트렌드 수집원 | Variables의 `TREND_SOURCES` 에 쓸 것만 쉼표로 나열 (아래 표의 이름) |

### 마스코트

- 캐릭터의 모델은 `assets/mascot_source.jpg` 의 실제 고양이입니다: 동그란 얼굴, 크림색 가슴 털, 초콜릿색 얼굴·귀·다리·꼬리, 푸른 테두리의 크고 동그란 눈. "마스코트 만들기"는 이 사진을 참조해 손그림 캐릭터 기준 그림(`assets/mascot.png`)을 만듭니다.
- 저장소가 공개이므로 이 사진도 함께 공개됩니다. 공개하고 싶지 않으면 기준 그림을 만든 뒤 `mascot_source.jpg` 를 저장소에서 지워도 됩니다(이후 카드는 `mascot.png` 만 참조합니다).
- 사진을 바꾸면 다른 고양이로 만들 수 있습니다. 이때 `bot/images.py` 의 `MASCOT_DESCRIPTION` 도 그 고양이에 맞게 고치세요. 사진이 없으면 글 묘사만으로 기준 그림을 만듭니다.
- 화풍은 "또렷한 잉크 선 + 셀 채색에 은은한 붓 질감, 삐죽한 털 표현, 크고 반짝이는 눈, 따뜻한 빛의 손그림 애니메이션 영화 느낌"으로 지정했습니다. 특정 스튜디오나 작품 이름은 프롬프트에 넣지 않았습니다. 이름을 넣으면 생성이 거부되거나 기존 작품을 닮은 그림이 나올 수 있고, 상업 채널에서는 상표·저작권 문제가 될 수 있기 때문입니다. 같은 이유로 캡션·해시태그에도 스튜디오 이름은 쓰지 않는 것을 권합니다.
- **같은 캐릭터 유지**: 매 카드를 그릴 때 `assets/mascot.png`(기준 그림)를 참조 이미지로 함께 보내 같은 고양이로 그리게 합니다. 그래도 포즈나 장면에 따라 무늬·비율이 조금씩 달라질 수 있습니다.
- 기준 그림이 없으면 글 묘사만으로 그려서 카드마다 생김새가 더 많이 달라집니다. 꼭 먼저 만들어 두세요.
- 직접 그린 캐릭터가 있다면 `assets/mascot.png` 로 넣으면 그 캐릭터로 그려집니다(이때 `MASCOT_DESCRIPTION` 도 그 캐릭터에 맞게 고치세요).
- 글자는 AI 그림에 넣지 않고 말풍선에 직접 그려 넣으므로 한글이 깨지지 않습니다.

| 이름 | 무엇을 | 쓰임 | 비고 (2026-11-15 확인) |
|---|---|---|---|
| `google` | 구글 트렌드 실시간 검색어 RSS | 후보 | 구글이 내보내기 버튼으로 제공하는 피드. 관련 기사 제목이 함께 옴 |
| `daum` | 다음 첫 화면 '실시간 트렌드' | 후보 | robots.txt가 첫 화면만 허용 → 첫 화면만 읽음. 연예 주제 비중이 높음 |
| `zum` | 줌 첫 화면 'AI 이슈트렌드' | 후보 | robots.txt가 첫 화면만 허용 → 첫 화면만 읽음 |
| `signal` | 시그널(signal.bz) 실시간 검색어 | 후보 | robots.txt 허용 |
| `google_news` | 구글 뉴스 '엔터테인먼트' 섹션 RSS | 후보 | 같은 사건을 다룬 여러 언론사 기사가 묶여서 옴. 2곳 이상 보도한 것만 사용 |
| `youtube` | 유튜브 한국 인기 동영상 | 참고 신호 | 공식 API, 키 필요 |
| `ppomppu` | 뽐뿌 HOT 게시글 제목 | 커뮤니티 | robots.txt 허용. GitHub 서버에서 수집 확인됨 |
| `fmkorea` | 에펨코리아 '포텐 터짐' 인기글 제목 | 커뮤니티 | robots.txt가 인기글 목록 허용. 단, GitHub 서버에서는 접속 차단(HTTP 430) → 한국 일반 회선에서만 수집됨 |
| `ruliweb` | 루리웹 베스트 인기글 제목 | 커뮤니티 | robots.txt 허용. 단, GitHub 서버에서는 접속이 막힘 → 한국 일반 회선에서만 수집됨 |
| `dcinside` | 디시 '실시간 베스트' 글 제목 | 커뮤니티 | robots.txt가 일반 봇 허용. 단, GitHub 서버에서는 접속이 막힘 → 한국 일반 회선에서만 수집됨 |
| `x` | X(트위터) 트렌드 | 후보 | 유료, 토큰이 있을 때만 |

- **커뮤니티**는 주제 선정의 1순위입니다. 인기글 제목만 읽고(본문은 읽지 않음), Claude가 제목에서 연예·문화·밈 화제를 골라 검색어로 바꾼 뒤 뉴스로 확인되면 맨 앞 후보가 됩니다. 카드에 들어가는 사실은 뉴스에서 확인된 것만 씁니다.
- **후보**는 뉴스로 내용이 확인되면 카드뉴스 주제가 될 수 있습니다. 여러 수집원에 함께 나온 이야기를 우선합니다.
- **카페·블로그 반응**: 후보마다 네이버 공식 검색 API로 카페와 블로그에 방금 올라온 글을 최신순으로 몇 건씩 가져와 붙입니다(네이버 검색 키 하나로 뉴스·카페·블로그 모두 사용). 반응이 활발한 주제를 우선하고 "반응" 카드의 분위기를 잡는 데 쓰며, 특정 글을 인용하거나 사실 근거로 쓰지는 않습니다. 카페의 인기글 목록 자체는 로그인이 필요하고 네이버가 자동 수집을 막고 있어 직접 긁지 않습니다.
- **참고 신호**는 무엇이 화제인지 가늠하는 데만 쓰고, 원고의 사실 근거로는 쓰지 않습니다. 커뮤니티 글과 영상 제목은 확인되지 않은 내용이기 때문입니다.
- 웹 페이지를 직접 읽는 수집원(`daum`, `zum`, `signal`, `dcinside`)은 매번 robots.txt를 먼저 확인하고, 사이트가 막으면 자동으로 건너뜁니다. 요청은 봇임을 밝히는 이름(`cardnews-bot`)으로 한 시간에 한 번만 보냅니다.
- **넣지 않은 곳**: 네이트 실시간 이슈 키워드, 네이트판, 엠엘비파크는 robots.txt가 자동 수집을 전부 막고 있고, 클리앙은 추천글 목록을 막고 있습니다. 더쿠와 인스티즈는 robots.txt에 AI 수집·스크랩 봇을 거부한다고 명시해 두었습니다. 네이버는 실시간 검색어 서비스 자체가 없습니다.

### 토큰 자동 갱신 (권장)

GitHub → Settings → Developer settings → Personal access tokens 에서 이 저장소의 **Secrets 쓰기 권한**이 있는 토큰을 만들어 Secrets에 `GH_PAT` 으로 등록하면, 매주 `refresh-token.yml` 이 인스타 토큰을 갱신해 줍니다. 등록하지 않으면 60일마다 토큰을 직접 새로 발급해 `IG_ACCESS_TOKEN` 을 바꿔야 합니다.

### Threads 반응 추가 (선택)

Threads에는 "실시간 트렌드"를 주는 공식 API가 없어서 트렌드 수집원으로는 쓰지 못합니다. 대신 Threads **키워드 검색 API**로 선정된 주제의 반응을 원고에 참고시킬 수 있습니다. Meta 앱 심사에서 `threads_keyword_search` 권한을 승인받은 뒤 Secrets에 `THREADS_ACCESS_TOKEN` 을 넣으면 자동으로 켜집니다.

## 4. 꼭 알아둘 점

- **전체를 실제로 돌려본 것은 아닙니다.** 수집원 6곳(구글 트렌드·구글 뉴스·다음·줌·시그널·디시)은 2026-11-15에 실제 응답을 받아 형식을 확인하고 그 형식으로 점검했습니다. 나머지(네이버 검색, 유튜브, Claude, AI 그림 생성과 캐릭터 유지, 인스타그램 게시)는 공식 문서 기준으로 작성해 가짜 응답으로 흐름만 점검했습니다. 첫 실행에서 오류가 나면 Actions 로그의 메시지를 그대로 보여주시면 고칠 수 있습니다.
- **수집원은 깨질 수 있습니다.** 다음·줌·시그널·디시는 공식 API가 아니라 화면에 실린 내용을 읽는 방식이라, 사이트가 화면을 바꾸면 그 수집원만 실패합니다. 한 곳이 실패해도 나머지로 계속 돌아가고, Actions 로그의 "수집 결과"에 수집원별로 ✓/✗ 가 찍힙니다. ✗ 가 계속되면 로그를 보여주세요.
- **GitHub 서버에서는 막힐 수 있습니다.** 수집원 형식은 한국의 일반 인터넷 회선에서 확인했습니다. GitHub Actions 서버(해외 데이터센터)에서는 일부 사이트가 접속을 거부할 수 있고, 그 경우 해당 수집원만 ✗ 로 빠집니다.
- **이미지 주소**: 카드 이미지는 저장소의 `media` 브랜치에 최신 회차만 올라가고, 인스타그램이 `raw.githubusercontent.com` 주소에서 가져갑니다. 만약 인스타그램이 이 주소를 거부하면 `PUBLIC_BASE_URL` 을 Cloudflare R2 같은 이미지 호스팅 주소로 바꿔야 합니다.
- **완전 자동의 한계**: 금지 키워드와 "언론사 2곳 이상" 조건으로 걸러내지만, 오보를 그대로 요약하거나 맥락을 놓칠 가능성은 남습니다. 문제가 된 게시물은 인스타 앱에서 바로 삭제하고, 해당 단어를 `BLOCKED_KEYWORDS` 에 추가하세요.
- **이미지 비용이 가장 큽니다.** 게시물 하나에 그림 4~5장이 들어가므로, 매시간 게시하면 하루 최대 120장 안팎을 생성합니다. 마스코트 모드는 매번 기준 그림을 함께 보내기 때문에 장당 비용이 조금 더 듭니다. 요금은 OpenAI 요금표에서 품질별 장당 가격을 확인하고 월 한도를 걸어두세요. 부담되면 `IMAGE_QUALITY=low` 로 낮추거나 `MAX_POSTS_PER_DAY` 로 게시 수를 줄이세요.
- **이미지 한 장이 실패해도 게시는 계속됩니다.** 그 카드만 이미지 없는 디자인으로 대체됩니다.
- **실존 인물 이미지는 만들지 않습니다.** 연예 주제라도 그림에는 마스코트와 소품·장소만 나오고, 사람이 필요하면 멀리 있는 작은 실루엣으로만 표현하도록 되어 있습니다. 연예인 얼굴을 AI로 생성하면 초상권·퍼블리시티권 문제가 생깁니다. 드라마·영화의 실제 장면이나 포스터도 만들지 않습니다.
- **AI 표시**: 게시할 때 인스타그램의 AI 생성 라벨이 붙고, 캡션과 마지막 카드에도 AI로 만들었다는 문구와 출처가 들어갑니다.
- **기사 저작권**: 기사 문장을 옮기지 않고 사실만 다시 쓰도록 지시했지만, 뉴스 요약 채널은 언론사 항의를 받을 수 있습니다. 출처 표기를 지우지 마세요.
- **게시 빈도**: 인스타그램 API 한도는 24시간 100건이라 매시간 게시도 가능하지만, 신생 계정이 하루 20건 넘게 올리면 도달이 떨어질 수 있습니다. `QUIET_HOURS=1-6`, `MAX_POSTS_PER_DAY=12` 정도로 시작하는 것을 권합니다.
- GitHub의 예약 실행은 몇 분~수십 분 늦어질 수 있습니다.
