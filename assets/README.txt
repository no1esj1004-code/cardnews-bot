이 폴더에는 채널 마스코트 그림이 저장됩니다.

- mascot_source.jpg  모델이 되는 실제 고양이 사진 (기준 그림을 만들 때만 사용)
- mascot.png         캐릭터 기준 그림 (매 카드가 이 그림을 참조해 같은 캐릭터로 그려집니다)
- mascot_wave.png    마지막 카드에 들어가는 인사하는 그림

Actions 탭의 "마스코트 만들기 (수동)"을 실행하거나, 내 컴퓨터에서 python main.py mascot 을 실행하면
mascot.png 와 mascot_wave.png 가 만들어집니다. 직접 그린 그림이 있다면 같은 이름으로 넣어도 됩니다.
